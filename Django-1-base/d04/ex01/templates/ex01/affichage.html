Ex01 : Processus d’affichage d’une page statique.

Le processus d'affichage d'une page statique suit le cycle requête-réponse de Django :

  1. Requête : L'utilisateur envoie une requête HTTP via son navigateur vers une URL spécifique.
  2. Routage (urls.py) : Django intercepte l'URL et l'associe à une fonction ou classe de vue (views.py).
  3. Vue (views.py) : La vue traite la logique (pour une page statique, elle prépare simplement le contexte minimal) et appelle le moteur de rendu avec un template.
  4. Template : Le moteur de template génère le code HTML final à partir du fichier template.
  5. Réponse : La vue retourne le tout sous forme d'objet HttpResponse renvoyé au navigateur.
