Ex01 : Moteur de template.

Le moteur de templates par défaut de Django permet de structurer dynamiquement l'affichage grâce à plusieurs fonctionnalités clés :

  • Affichage de variables : Permet d'injecter des données issues du contexte de la vue à l'aide de doubles accolades {% verbatim %}{{ variable }}{% endverbatim %}.
  • Les blocs : Permettent de définir des zones modifiables dans un template parent prêtes à être surchargées via {% verbatim %}{% block nom %}{% endblock %}{% endverbatim %}.
  • Les structures de contrôle if : Permettent d'afficher conditionnellement du contenu selon l'évaluation d'expressions.
  • Les boucles for ... in : Permettent d'itérer facilement sur des listes ou des objets transmis par le contexte.
